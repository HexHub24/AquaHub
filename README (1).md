# AquaHub

Aquarium tracking app. Track tanks, livestock, water parameters, and bioload — with the math actually done right.

## Stack

- **Frontend:** Vanilla JS, HTML, CSS (PWA-ready)
- **Backend:** Supabase (Postgres + Auth + Row Level Security)
- **Hosting:** Cloudflare Pages
- **Payments:** Stripe (later)

## Status

🐠 Pre-alpha — auth and database wired up, features in progress.
